Privacy policy

Formula Formatter for Excel · last updated 22 November 2026

Summary

Formula Formatter for Excel does not collect, store, transmit or sell any personal data or workbook content.

What the add-in processes

When you run Beautify, Minify, Beautify All or Minify All, the add-in reads the formulas of the selected cells or of the workbook through the Excel JavaScript API, reformats them inside Excel on your device, and writes them back. This processing happens entirely in the add-in's code running inside Excel. No formula, cell value or file content is sent to any server.

What is stored

Your preferences (layout density, indentation, spacing, separator) are stored in the browser storage of the add-in on your device. Custom keyboard shortcuts are stored by Microsoft Office in your Office settings. The add-in author has no access to either.

Hosting

The add-in's static files (HTML, JavaScript, icons) are served by GitHub Pages. Like any web host, GitHub may log technical request data such as IP addresses when Excel downloads these files. See the GitHub Privacy Statement. The add-in also loads Microsoft's Office JavaScript library from Microsoft's servers, covered by the Microsoft Privacy Statement.

No tracking

The add-in contains no analytics, advertising, cookies or third-party trackers.
